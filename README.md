# Jan Žižka a Třetí úderná

Statický web o majoru Janu Žižkovi, československých legiích v Rusku a románu
Třetí úderná.

## Otevření

Otevřete `index.html`, který přesměruje na `web/index.html`.

Web nevyžaduje build ani lokální server. Interaktivní čtečka používá datový soubor
`web/data/novel-data.js`, vygenerovaný z upravených přepisů ve složce
`Přepis - upravený`.

## Obsah

- životopisná osa Jana Žižky
- pramenná vrstva s rozpory v datech
- interaktivní trasa legionářské anabáze
- čtečka všech dílů Třetí úderné
- režim "Žižkova stopa"
- archiv lokálních dokumentů, PDF a audio souborů
